    FIELD GUIDE

    ModScope 快速说明

    它检查什么

    • 缺失的必需依赖、依赖版本不满足
    • Minecraft / Java / 加载器不匹配
    • 重复 MOD ID、重复 JAR、内置 JAR 重名
    • MOD 元数据声明的互斥关系
    • 同名类覆盖、Mixin 配置 / refmap 重名
    • 资源命名空间重叠与文件损坏

    支持的元数据

    fabric.mod.jsonquilt.mod.json META-INF/mods.tomlneoforge.mods.toml mcmod.infolitemod.json riftmod.jsonMANIFEST.MF 推断

    怎么得到最准确的结果

    1. 选择正确的 mods 文件夹。只扫描第一层文件；子文件夹中的 JAR 不会被游戏加载。
    2. 填写 Minecraft 版本。留空时仍会检查各 MOD 声明的版本约束是否有交集，但不会逐个比对目标版本。
    3. 选择实际加载器。自动检测会以出现次数最多的加载器生态为准。
    4. 深度扫描建议开启。它会比对 class 与 Mixin，但大整合包会多花几秒钟。

    不能保证什么

    这是一款静态分析工具。它不会启动游戏，也不会读取运行时日志，因此无法可靠判断所有事件优先级、Mixin 注入点重叠、配方覆盖或配置项冲突。元数据写错、动态注册冲突仍需结合实际启动日志排查。
